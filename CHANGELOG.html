Guide Structure

Each faction guide includes:

  1. Introduction - Faction identity and playstyle overview
  2. Faction Components
    • Home System & Commodities
    • Starting Fleet
    • Faction Abilities
    • Starting & Faction Technologies
    • Leaders (Agent, Commander, Hero)
    • Promissory Note
    • Alliance
    • Mech
    • Flagship
    • Breakthrough
    • Slice and Draft Considerations
  3. Technology Paths - Recommended tech progressions with alternatives
  4. Round 1 Priorities - Opening strategy guidance
  5. Strategy Card Priorities - Pick order recommendations
  6. Objective Analysis - Faction-specific objective ratings
  7. Alliance Priority Rankings - Commander ability synergies
  8. Game Phase Strategy - Early/Mid/Late game guidance
  9. End Notes - Player experience summary

Visual Features

Tech Coloring: - Blue (Propulsion) technologies displayed in blue - Red (Warfare) technologies displayed in red - Green (Biotic) technologies displayed in green - Yellow (Cybernetic) technologies displayed in yellow

Tech Icons: - Official TI4 tech type icons for prerequisites - Single icons for base prereqs (e.g., one blue arrow for Propulsion) - Multiple icons for higher prereqs (e.g., two red shields for RR) - Mixed icons for unit upgrades (e.g., BBY shows two blue + one yellow) - Synergy notation with icons (e.g., Blue↔︎Red for Breakthrough abilities)

Dark Space Theme: - Custom CSS with space-themed dark background - Gold accent colors - Responsive design for mobile/desktop - Faction icon integration

Reference Materials

  • Glossary - Community terminology and shorthand explanations
  • Technology Reference - Complete tech list with colors and prereqs
