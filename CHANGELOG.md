# Changelog

---

## Version 0.1 - December 25, 2024

### Features

**30 Faction Guides**
- Complete strategy guides for all Base Game, Prophecy of Kings, Codex, and Thunder's Edge factions
- Each guide covers: faction overview, components, tech paths, round priorities, strategy card picks, objective ratings, alliance rankings, and phase-by-phase strategy

**Tech Visualization**
- Technology names colored by type (Blue/Red/Green/Yellow)
- Official tech icons for prerequisites replacing letter notation
- Synergy notation with icons for Breakthrough abilities

**Reference Materials**
- Glossary explaining community terminology and shorthand
- Technology reference with complete tech list

**Visual Theme**
- Dark space-themed design
- Faction icons on index page
- Responsive layout for desktop and mobile

**Format**
- Markdown source files
- HTML output via Pandoc
- Hosted on GitHub Pages
